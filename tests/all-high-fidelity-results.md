# 全部 high 与整稿事实保真回归

日期：2026-10-18。模型保持 `deepseek-flash`。这是 [推理强度对照测试](reasoning-effort-results.md) 之后的实施与补测，不把此前关闭思考的辅助步骤算作 high 测试。

## 实施范围

- 原稿批改、完整稿生成、独立短复核、整稿保真、教学检查全部显式 `thinking.enabled` / `reasoning_effort=high`，真实预览会拒绝任何不符合的上游请求。
- 原稿和整稿任务仍各自受原有 90 秒截止时间限制。核心判稿文件 `worker/current-review.js` 未改，LF 归一化 SHA-256 为 `bb1762c0735637e4ca511d70bf0f8d011165234f2f8cf638db293a13227085e5`。
- high 推理与最终 JSON 共用 token 额度：教学检查和独立恢复使用 8192，原稿、生成、整稿保真使用 16000。不把截断 JSON 当作可靠结论。
- 生成稿不能自行添加生活经历、身份、支持记录、精确数字、奖励和承诺。喜欢讲糗事不等于提供过某件具体糗事。保真按每句核对来源，原稿/场景引文必须存在，遗漏、重复、无依据和不确定事实均不放行；局部已知假经历在生成和保存稿重查时均先拦截。
- 真实能力边界继续保留，但不强迫台词逐字复述不会唱跳、不擅长接词、说话慢等背景；不能反过来说会，也不能安排相应活动。同一已知经历的少量同义词和逗号调整交给独立语义核对，不能据此换对象、补新事件。
- 生成优先自然精简，一般 80～180 字；这只是写作偏好，不能成为评分门槛，也不能为了缩短漏改问题或丢掉有效内容。
- 完整稿独立复核使用现有短证据合同，同一原始评分规则前缀、两项核心、风险类别、原文引用和安全闸门均保留；不再先生成另一份冗长带教报告。解释中的虚构引文也检查，不只检查独立 quote 字段。
- 单次整稿任务只按完全相同的候选稿复用已经验证成功的判断/保真结果；任何改字都重新检查。失败环节有一次任务内重试，成功环节不重复调用，仍要求两项都通过且不可变凭证保存成功才交付 ready。
- 普通原稿若较早进入恢复判断，可使用原任务剩余预算，恢复总窗最多 50 秒、单次最多 25 秒、最多两次；默认短复核仍是 25 秒总窗。此配置只由服务端决定，不能由学员延长。

## 测试隔离与判据

Cloudflare remote preview 继承现有服务的模型密钥，但不挂生产 KV/持久对象；每次固定虚构稿使用内存存储和独立入口码，不读线上案例库、学员稿或本地密钥文件。原始结果只记录最终 JSON、耗时和用量，不记录凭据、请求头或模型推理文本。

保真测试同时包含应拒绝的编造和应接受的正常改法。完整流程为原稿批改 → 整稿生成 → 独立评分与事实核对 → 全新缓存下重判交付稿；人工另看交付稿是否捏造事实。HTTP 200 或 `passed` 本身不代表事实保真。

## 必须保留的失败与修正记录

- `preserve-r2`：17 例中 4 例未符合预期，两例超时、两例因省略负面背景句而误拒；据此明确保留有效内容和能力边界不等于逐字复述。
- `preserve-r3`：17 例中 16 例符合预期，固定场景加邀请的正常稿有一次 30 秒超时。该例独立重测两次均接受（16.962 / 18.033 秒）；原超时仍计作失败，不能改记成功。
- `recovery-r1`：四类真实 high 短复核均得到正确结果，耗时 5.936～19.389 秒。
- `flow-r1`：第一条原稿已有结果，整稿因重复长报告和保真超时耗尽预算，未交付 ready；第二条主动停止，没有算作完成。由此改用同标准短复核，并复用同任务同稿的成功检查。
- `flow-r2`：能力边界稿的独立模型判断和保真均给出通过，但解释中的非逐字概括引号被证据闸门拒绝，系统仅用约 33 秒就提前返回 draft。另一条整稿 ready、全新缓存重判通过。由此补明确引文要求，并修复另一检查已经通过时的有界重试。
- `flow-r3`：能力边界完整流程 ready、全新缓存重判通过，原稿 34.684 秒、整稿 27.085 秒。另一条在主报告校验失败后，独立 high 恢复 25 秒超时，总任务约 54.791 秒即返回 503，未利用剩余预算。由此增加服务端可选恢复窗口，但不延长原 90 秒任务上限。

这些失败说明提高推理强度本身不能保证可靠交付。本次有限固定样本也不能当作线上成功率；线上仍须用实际任务统计确认。

`flow-final` 两条均 ready，全新缓存重判均 passed；实际发出的所有模型请求都为 high。人工检查未发现新编具体经历或能力；已存在的有效内容和选择保留，实际缺口得到修复。

- `recovery-final` 默认 25 秒短窗：4 类中 2 类交付正确判断，借贷压力例首请求超时；空泛扣字例在正确核心判断之后，因为教学解释中明确提出的新概括被误当当前稿引文而请求修正，继而超时。两例都计为未完成，不能称 4/4。
